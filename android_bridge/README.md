# 🤖 Nova Assist (Android Bridge App)

Android OS の **「デフォルトのデジタルアシスタントアプリ」** として機能する超軽量ブリッジネイティブアプリです。

---

## 🌟 主な機能
1. **アシスタント Intent（`ACTION_ASSIST`）の受信**:
   - 電源ボタン長押しや画面端スワイプ（ホームアシスタントジェスチャー）で即座に呼び出し可能。
2. **即時音声認識トリガー（`?assist=1`）**:
   - アシスタントとして起動されると、スマートホームダッシュボードの Nova 音声入力（マイク）が自動的にスタンバイ状態になり、すぐに話しかけられます。
3. **PWAと完全連携**:
   - バックエンドおよびUIの更新はすべて Web サーバー側（`index.html` / Python）で行われるため、このブリッジアプリを一度インストールすれば、以降のアップデートも0秒で反映されます。

---

## 📲 インストール＆設定手順

1. GitHub リポジトリの **Releases**（または Actions の Artifacts）から `NovaAssist.apk` をダウンロードしてAndroidにインストールします。
2. Android の **「設定」➔「アプリ」➔「デフォルトのアプリ」➔「デジタルアシスタントアプリ」**（または「アシスタントと音声入力」）を開きます。
3. デフォルトアシスタントとして **「Nova Assist」** を選択します。
4. 電源ボタンの長押しや、ナビゲーションバーの角からのスワイプジェスチャーを行うと、Nova が即座に起動します！
