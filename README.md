# スマートホーム・ダッシュボード UI モックアップ

`/home/soh/dashboard/1.png`、`2.png`、`3.png` のデザインを忠実に再現した、ダークモード対応のスマートホーム・ダッシュボード UI プロトタイプです。

## 特徴
- **デザイン再現性**: Home Assistant / Material 3 準拠のダークモードスタイル（カラー、角丸、アイコン、タイポグラフィ）。
- **アニメーション**: タイルタップ時に、各詳細操作画面が下から滑らかにスライドアップ（ボトムシートアニメーション）。
- **レスポンシブ**: スマートフォン・PC両方の表示に対応。
- **純粋なフロントエンド**: 画像依存なし（Tailwind CSS CDN + インライン SVG のみ）。
- **インタラクション（モック）**:
  - `ライト` タイルをタップ → ライト詳細画面（画面3）が下から表示。スライダーをタップすると点灯状態の切り替えが可能。
  - `エアコン` タイルをタップ → エアコン詳細画面（画面2）が下から表示。温度の「＋」「ー」ボタンで円弧ゲージと温度の連動変化が可能。
  - タイル上のクイックボタン（冷房、除湿、電源）の切り替え。
  - 「✕」ボタンまたは背景タップでシートを閉じる。

## プレビュー方法

ブラウザで直接 [`index.html`](file:///home/soh/dashboard/index.html) を開くか、またはローカルサーバーを起動して確認できます。

```bash
cd /home/soh/dashboard
python3 -m http.server 8080
```
起動後、ブラウザで `http://localhost:8080` にアクセスしてください。
